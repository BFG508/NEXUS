# BEAM 📡

**B**roadside **E**lectromagnetic **A**rray **M**odeler

BEAM is a Python exploratory simulation for idealized dipole and phased-array concepts. The visual demonstration remains available as a Jupyter notebook, while reusable uniform-linear-array calculations are separated into the `beam/` package for testing and NEXUS integration.

The project is intended for array-factor studies, electronic-steering demonstrations, and integration experiments. It is not a full-wave electromagnetic solver and does not currently model a complete RF link budget, mutual coupling, detailed element impedance interactions, propagation losses, or hardware calibration effects.

## Core capabilities

### Dipole and array-pattern demonstrations

`BEAM.ipynb` contains the visual engineering demonstration, including a half-wave dipole example, frequency/pattern exploration, linear-array construction, and 2D/3D radiation visualizations.

The reusable numerical core in `beam/array.py` focuses on normalized ideal array-factor behavior so integrations do not depend on notebook execution.

### Uniform linear-array factor

The core evaluates an idealized uniformly weighted linear array from element count, spacing, observation angle, and progressive phase. It is suitable for demonstrating main-lobe steering and the appearance of sidelobes under the assumed ideal model.

### Electronic beam steering

Progressive phase is derived from the standard steering relation used by the project:

\[
\alpha = -k d \cos(\theta_0),
\]

where `k` is the wavenumber, `d` the element spacing, and `theta_0` the requested steering angle.

### Visualization

The notebook uses NumPy and Matplotlib to construct polar and Cartesian cuts and 3D visualizations. Visualization is a demonstration layer; tested integration calculations live outside the notebook.

## NEXUS integration

BEAM provides three current compatibility adapters under `integrations/`:

### SPARTAN beam steering

```bash
python integrations/spartanBeamSteering.py
```

The adapter reads SPARTAN fleet state, computes steering phase, applies a separate pointing-error model, and evaluates normalized gain at the target direction. Target direction and commanded pointing are deliberately distinct so the result is not perfect by construction.

### GAIA radio-detectability proxy

```bash
python integrations/gaiaSetiScanner.py
```

The adapter evaluates an exploratory radio-detectability proxy only for GAIA rows containing a real positive catalog distance. Missing distances are skipped rather than synthesized. This is not a validated SETI sensitivity calculation.

### SCALE jamming profile

```bash
python integrations/applyJammingProfile.py
```

This adapter consumes the `jamming_profile.json` generated by SCALE and applies the profile to BEAM's idealized array calculations.

These scripts are compatibility adapters rather than stable NEXUS protocols.

## Reproducibility

The reusable deterministic array-factor calculations return the same result for the same numerical inputs. Integrations that introduce randomized pointing or scenario effects should be executed with their documented seed/state where exposed.

The notebook itself is an interactive demonstration and may contain execution-state metadata; validation should rely on the tested `beam/` core and scripts rather than notebook cell history.

## Python requirements

BEAM targets Python 3.10+.

Create and install a local environment on Unix-like systems with:

```bash
cd BEAM
./setup_unix.sh
```

On Windows PowerShell:

```powershell
cd BEAM
.\setup_windows.ps1
```

Manual installation:

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
```

The principal numerical/visual dependencies are NumPy and Matplotlib. Development tests use `pytest`.

## Usage

After installing dependencies, open the notebook for the visual demonstration:

```bash
jupyter notebook BEAM.ipynb
```

Or import the reusable array functionality from Python:

```python
from beam.array import array_factor
```

Integration scripts are run independently after their required producer data has been generated.

## Tests and CI

Run the complete Python test suite with:

```bash
cd BEAM
pytest -q
```

`.github/workflows/beam.yml` installs runtime/development requirements and runs `pytest` on a clean Ubuntu runner.

## Important modeling assumptions

- The tested numerical core represents an ideal uniformly weighted linear-array factor.
- Mutual coupling, finite-conductor effects, radome/platform scattering, detailed impedance matching, polarization mismatch, channel propagation, and a complete RF link budget are outside the current core model.
- The GAIA integration is an exploratory detectability proxy, not a validated radio-astronomy sensitivity model.
- SPARTAN steering results depend on the adapter's pointing-error assumptions in addition to the ideal array factor.
- SCALE jamming integration applies a compatibility profile to an idealized model and is not an electronic-warfare qualification analysis.
