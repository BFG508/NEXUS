# Raw corpus data

Los textos de investigación reales deben almacenarse aquí localmente siguiendo la estructura elegida en `config/corpora.toml`.

Por defecto Git ignora los corpus añadidos por el usuario para evitar redistribución accidental de material protegido. Los seis archivos `synthetic_*` incluidos son fixtures originales creados exclusivamente para demostrar y probar el pipeline.

Los fixtures sintéticos se distribuyen bajo la licencia MIT del repositorio.
