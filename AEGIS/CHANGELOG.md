# Changelog

## 0.1.0 - 2026-09-10

### Added

- Exponential and Weibull lifetime models.
- Series, parallel, and heterogeneous k-out-of-n system reliability.
- Repairable steady-state availability for exponential components.
- Component MTTF calculations.
- Independent-event AND/OR fault trees.
- CTMC generator validation, transient uniformization, and steady-state analysis.
- Reproducible SplitMix64 Monte Carlo mission simulation.
- Wilson 95% confidence intervals.
- TOML/JSON configuration loading and JSON reports.
- `validate`, `analyze`, `monte-carlo`, `demo`, and `version` CLI commands.
- Numerical, edge-case, parser, Markov, fault-tree, Monte Carlo, and CLI tests.
- Dependency-free Monte Carlo benchmark.
