# Generated results

Ejecuta:

```bash
julia --project=. scripts/run_pipeline.jl
```

El pipeline escribirá aquí tablas CSV, embeddings, figuras SVG, `report.md` y metadatos de ejecución.

Los resultados derivados se ignoran en Git por defecto. Para una publicación, archívalos junto con el tag de código, configuración y checksums del corpus.
